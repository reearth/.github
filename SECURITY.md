# Security Policy

This policy applies to the Re:Earth repositories. If a repository ships its own
`SECURITY.md`, that one takes precedence for the project it lives in.

## Reporting a vulnerability

Email [community@reearth.io](mailto:community@reearth.io) with the details. To
avoid zero-day exposure, please do not report security issues in a public place
such as GitHub Issues or Discussions.

A useful report usually includes:

- the repository and version (or commit) affected,
- steps to reproduce or a proof of concept,
- the impact you expect, and
- any suggested fix, if you have one.

We'll confirm we received your report and keep you updated while we work on a
fix. Please give us reasonable time to release a patch before any public
disclosure.

## Supported versions

Each product follows its own release and patch cadence. Security fixes land on
the actively maintained release lines, which are noted in each repository's
releases and changelog.
