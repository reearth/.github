# Contributing to Re:Earth

Thanks for taking the time to contribute. This guide applies across the Re:Earth
repositories. Individual repos may add their own notes in their own
`CONTRIBUTING.md` or README, so check there too.

## Before you start

Read the [contribution guide](https://docs.reearth.io/developer-guide/contribution)
in our developer docs. It covers the development process, how to propose bug
fixes and improvements, release policy, and how to build and test your changes.

## Code of Conduct

We follow a [Code of Conduct](./CODE_OF_CONDUCT.md). By taking part in the
project you agree to it. Please read it before contributing.

## Good first issues

If you're new to the project, the `good first issue` label is a good place to
start. You can browse them across the org here:
https://github.com/search?q=org%3Areearth+label%3A%22good+first+issue%22+state%3Aopen&type=issues

## Reporting bugs and requesting features

Open an issue in the relevant repository using the bug report or feature request
template. Search existing issues first so we can avoid duplicates.

## Pull requests

- Branch from `main` and keep each PR focused on one change.
- Fill in the pull request template, including how you tested the change.
- Match the existing code style of the repository you're working in.
- Note any breaking changes or migrations so they can be handled at release time.

## A thank-you for contributors

If you commit to the Re:Earth source code and your pull request is merged, we'll
issue you a free Re:Earth cloud account, valid for one year from that date.

To claim it, contact us after your PR is merged from the email address on your
GitHub account, at [community@reearth.io](mailto:community@reearth.io).
