# Support

Thanks for using Re:Earth! Here is where to go, depending on what you need.

## I have a question about how to use something

Start with the documentation:

- [Documentation](https://docs.reearth.io/en/) — user guides for Visualizer, CMS and Flow
- [Developer documentation](https://visualizer.developer.reearth.io/) — APIs and plugin development

If the docs do not answer it, ask on [**Discord**](https://discord.com/invite/XJhYkQQDAu). That is the fastest way to reach both other users and the maintainers, and it keeps the answer where the next person can find it.

Please do not open a GitHub issue for usage questions — issues are for defects and feature requests, and questions tend to sit there unanswered.

## I found a bug

Open an issue in the repository where the bug lives. Include the version or commit, what you expected, what happened, and the smallest set of steps that reproduces it.

## I want to request a feature

Open an issue in the relevant repository and describe the problem you are trying to solve, not only the solution you have in mind. That gives us room to suggest something that fits the product better.

## I found a security vulnerability

Do **not** open a public issue. Follow our [Security Policy](./SECURITY.md).

## I want to contribute

See [CONTRIBUTING.md](./CONTRIBUTING.md), then the `CONTRIBUTING.md` of the specific repository if it has one.

## Is a service down?

Check [status](https://github.com/reearth/status) for uptime of our hosted services.
