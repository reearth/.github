# Support

Here's where to go depending on what you need.

## Documentation

Start with the docs: https://docs.reearth.io. They cover setup, usage, and the
developer guide.

## Questions and bug reports

- For a bug or a feature request, open an issue in the relevant repository.
- For usage questions, check the docs first, then open an issue if you're still
  stuck.

Search existing issues before opening a new one.

## Re:Earth cloud and account help

For questions about the hosted Re:Earth service or your account, email
[support@reearth.io](mailto:support@reearth.io).

## Reaching the team

To contact the core committers directly, email
[community@reearth.io](mailto:community@reearth.io).

Security issues should go to the same address and not to public issues. See
[SECURITY.md](./SECURITY.md).
